Antes de começar: host, nome, endereço IP e prefixo ocultar / mostrar

Host

Qualquer aparelho com endereço IP: seu notebook, seu celular, uma impressora ou o servidor de um site. No laboratório, Host A e Host B são computadores da mesma rede local, como dois aparelhos na Wi-Fi da sua casa.

Nome (domínio)

www.claude.com não é um host: é um nome, um apelido fácil de lembrar. O DNS traduz esse nome para o endereço IP do servidor (o host de verdade). É o assunto da missão 6.

nome → DNS → endereço IP → servidor

Endereço IP

O número que os pacotes realmente usam. Funciona como um endereço de correspondência: uma parte diz a rua (a rede) e a outra diz o número da casa (o aparelho).

O que é o /24?

192.168.56.101/24

A barra diz quantos bits, contando da esquerda, são a rua (rede). Cada número tem 8 bits, então /24 = os 3 primeiros números. O que sobra é o aparelho: de .1 até .254. A missão 1 mostra isso bit a bit.
